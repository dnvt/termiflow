# Changelog

All notable user-facing changes are recorded here. Release entries use the
published tag and link to the corresponding GitHub release.

## Unreleased

- Keep changes grouped by user-visible behavior, compatibility, documentation,
  and maintenance.
- Record intentional visual or schema changes with their reviewed decision.

## [0.2.1] — 2026-08-03

- Fail-closed, policy-bound visual QA persistence with crash recovery,
  deterministic publication, and receipt reconciliation.
- Deterministic render contracts, architecture facts, generated diagrams, and
  scene-versus-legacy differential coverage.
- Reproducible release candidates, extracted-package validation, and expanded
  open-source contribution and release guidance.

## [0.2.0] — 2026-08-03

- Terminal-native Mermaid flowchart rendering with ASCII and Unicode styles.
- JSON graph input, subgraphs, cycles, labels, audit/critic output, and live
  preview modes.
- Locked Rust/MSRV, deterministic visual QA, package, and release workflows.
